# passing-funded-account-1

The proven, running slice of the general `quant` research repo — carved out
for one specific job: pass the first funded evaluation.

Not a rewrite. Not a fresh start. This is the code that's actually confirmed
to work, minus the ~850 files of active research, dormant experiments, and
unproven systems that don't belong in an execution-only repo.

**Start here:** `CLAUDE.md`, then `COLIN_V1.md`, then `ALTA_METHOD.md`.

**The proof, not just the claim:** `data/proof/backtest_trades_v015_2015_2024.csv`
is the real 411-trade sealed log every number in this repo traces back to.

**The daily check:** `python3 scripts/build_daily_verdict_page.py` — one page,
plain language, tells you whether today is a trade-live day and why.
